# 네이버쇼핑 연결 · 네이버/다음/구글 검색 등록

사이트 주소: https://moneyinsight.github.io/shop (도메인을 사면 그 주소로 다시 등록)

## 1. 네이버 검색 (네이버 서치어드바이저) — 무료
1. searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록 → 사이트 주소 입력
2. 소유 확인: 'HTML 태그' 선택 → content="……" 값을 config.json `naver_site_verification` 에 넣고 배포 → [소유확인]
3. 요청 → 사이트맵 제출: https://moneyinsight.github.io/shop/sitemap.xml
4. 요청 → RSS 제출(선택), 웹 페이지 수집 요청: 메인 주소

## 2. 구글 (Search Console) — 무료
1. search.google.com/search-console → URL 접두어 → 사이트 주소
2. 'HTML 태그' 값 → config.json `google_site_verification` → 배포 → 확인
3. Sitemaps → sitemap.xml 제출

## 3. 다음 (Daum 웹마스터도구) — 무료
1. webmaster.daum.net → 사이트 등록 → 사이트 주소
2. robots.txt 인증(안내 문구를 알려주시면 넣어 드림) → 사이트맵 제출

## 4. 네이버쇼핑 입점 (상품이 네이버 가격비교에 노출)
- 네이버 쇼핑파트너센터(adcenter.shopping.naver.com) → 쇼핑몰 등록 → 사업자 정보·통신판매업 신고번호 입력
- 상품 정보 연동: EP(상품 목록 파일) 주소 등록 → https://moneyinsight.github.io/shop/naver_ep.txt (사이트가 자동으로 만들고 매일 갱신)
- 심사 통과 후 노출 · 비용: 입점 무료, 판매 시 네이버쇼핑 수수료 2% (클릭당 광고는 선택)
- 심사 기준상 자체 도메인·결제(토스 실결제)·사업자 정보가 갖춰져 있어야 통과가 쉬움 → 도메인·토스 계약 후 신청 권장

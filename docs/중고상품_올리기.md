# 중고 상품 올리기

`data/중고상품.csv` 에 한 줄 = 상품 1개로 적고 커밋하면 사이트 '중고' 카테고리에 올라갑니다.

| 열 | 예시 | 설명 |
|---|---|---|
| 상품코드 | UD0001 | 비워두면 자동 생성 (UD로 시작) |
| 상품명 | 아이패드 9세대 64GB 와이파이 | 상품명 앞에 [중고 A급]이 자동으로 붙음 |
| 판매가 | 289000 | 숫자만 |
| 상태등급 | A | S(거의 새것) / A(사용감 적음) / B(사용감 있음) / C(기능 정상·외관 하자) |
| 상태설명 | 배터리 성능 91%, 화면 깨끗함 | |
| 하자 | 모서리 잔기스 1곳 | 적어 둔 하자는 반품 사유가 되지 않음 → 꼭 정확히 |
| 구성품 | 본체+충전기+케이블 | |
| 사용기간 | 1년 | |
| 대표이미지 | https://... | 실제 상품 사진 주소 (필수) |
| 추가이미지 | https://...1.jpg\|https://...2.jpg | 여러 장은 \| 로 구분 |
| 상세설명 | `<p>정상 작동 확인</p>` | HTML 가능 |
| 재고 | 1 | 0 이면 품절 |
| 판매상태 | 판매중 | 판매중 / 품절 |

- 중고는 수량 할인·중복 정리 대상이 아님 (한 점 한 점이 다른 상품)
- 반품·교환: 받은 날부터 7일 (전자상거래법상 중고도 청약철회 가능), 고지한 하자는 제외 — 상품 페이지에 자동 안내

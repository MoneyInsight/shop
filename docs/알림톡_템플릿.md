# 올채움 카카오 알림톡 템플릿

카카오 비즈니스(솔라피 > 카카오 알림톡 > 템플릿 등록)에 아래 문구를 **글자 하나 바꾸지 말고** 그대로 등록하세요.
승인되면 받은 템플릿 ID를 Netlify 환경변수 `KAKAO_TPL_키이름`에 넣으면 바로 발송됩니다.

## 넣어야 할 환경변수

| 이름 | 값 |
|---|---|
| SOLAPI_API_KEY | 솔라피 API Key |
| SOLAPI_API_SECRET | 솔라피 API Secret |
| SOLAPI_PFID | 솔라피에 연결한 카카오 채널 ID (pfId) |
| SOLAPI_SENDER | 솔라피에 등록한 발신번호 (예: 031-291-1004) |
| ADMIN_PHONE | 대표님 알림 받을 휴대폰 번호 |
| KAKAO_TPL_OFFER_NEW | 아래 `OFFER_NEW` 템플릿 승인 ID |
| KAKAO_TPL_OFFER_ACCEPT | 아래 `OFFER_ACCEPT` 템플릿 승인 ID |
| KAKAO_TPL_OFFER_REJECT | 아래 `OFFER_REJECT` 템플릿 승인 ID |
| KAKAO_TPL_ORDER_DONE | 아래 `ORDER_DONE` 템플릿 승인 ID |
| KAKAO_TPL_SHIPPED | 아래 `SHIPPED` 템플릿 승인 ID |
| KAKAO_TPL_ADMIN_ORDER | 아래 `ADMIN_ORDER` 템플릿 승인 ID |

키가 하나라도 없으면 알림톡은 보내지 않고, 주문·제안 처리는 정상으로 진행됩니다.

## OFFER_NEW

- 받는 사람: 공급사(직영은 대표)
- 보내는 때: 고객이 가격 제안을 보냈을 때
- 유형: 기본형 · 정보성

```
[올채움] 새 가격 제안이 도착했습니다.

상품: #{상품명}
수량: #{수량}개
판매가: 개당 #{판매가}원
제안가: 개당 #{제안가}원
제안번호: #{제안번호}

#{기한}까지 수락 또는 거절해 주세요. 기한이 지나면 자동으로 만료됩니다.

응답하기: #{링크}
```

## OFFER_ACCEPT

- 받는 사람: 고객
- 보내는 때: 가격 제안이 수락됐을 때
- 유형: 기본형 · 정보성

```
[올채움] #{고객명}님, 가격 제안이 수락되었습니다.

상품: #{상품명}
수량: #{수량}개
제안가: 개당 #{제안가}원 (합계 #{합계}원)
제안번호: #{제안번호}

#{기한}까지 아래 링크에서 주문하시면 제안 가격이 적용됩니다.

주문하기: #{링크}
```

## OFFER_REJECT

- 받는 사람: 고객
- 보내는 때: 가격 제안이 거절됐을 때
- 유형: 기본형 · 정보성

```
[올채움] #{고객명}님, 보내주신 가격 제안이 이번에는 수락되지 않았습니다.

상품: #{상품명}
제안번호: #{제안번호}
판매자 메시지: #{사유}

판매가로는 언제든 바로 주문하실 수 있습니다.

상품 보기: #{링크}
```

## ORDER_DONE

- 받는 사람: 고객
- 보내는 때: 결제가 완료됐을 때
- 유형: 기본형 · 정보성

```
[올채움] #{고객명}님, 주문이 완료되었습니다.

주문번호: #{주문번호}
상품: #{상품명}
결제금액: #{결제금액}원

영업일 기준 1~3일 안에 출고되며, 출고되면 다시 알려드립니다.

주문 조회: #{링크}
```

## SHIPPED

- 받는 사람: 고객
- 보내는 때: 송장번호를 넣고 배송중으로 바꿨을 때
- 유형: 기본형 · 정보성

```
[올채움] #{고객명}님, 주문하신 상품이 출고되었습니다.

주문번호: #{주문번호}
택배사: #{택배사}
송장번호: #{송장번호}

배송 조회: #{링크}
```

## ADMIN_ORDER

- 받는 사람: 대표
- 보내는 때: 새 주문이 들어왔을 때
- 유형: 기본형 · 정보성

```
[올채움] 새 주문이 들어왔습니다.

주문번호: #{주문번호}
상품: #{상품명}
결제금액: #{결제금액}원
받는 분: #{고객명}

발주와 송장 입력을 진행해 주세요.

관리자: #{링크}
```

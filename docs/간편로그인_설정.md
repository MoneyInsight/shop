# 네이버·카카오·구글 간편 로그인 켜기 (모두 무료)

코드·화면은 완성돼 있어요. 서버를 켠 뒤 아래 키만 서버 설정값(환경변수)에 넣으면 해당 버튼이 바로 켜집니다.
(키가 없는 버튼은 손님에게 "준비 중"으로 보이고, 비회원 주문은 그대로 돼요.)

먼저 서버 주소를 정해야 해요. 아래 `{서버}` = 예) https://ttaengjab.netlify.app/api

## 1. 네이버 — developers.naver.com
1. Application → 애플리케이션 등록 → 사용 API: **네이버 로그인**
2. 제공 정보: 이름, 이메일, 휴대전화번호 (필수/선택 체크)
3. 서비스 URL: https://moneyinsight.github.io/shop
4. Callback URL: `{서버}/auth/callback/naver`
5. 받은 값 → `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
6. 손님 모두가 쓰려면 **검수 요청** (개발 중엔 등록한 멤버만 로그인 가능)

## 2. 카카오 — developers.kakao.com
1. 내 애플리케이션 → 앱 추가 (앱 이름: 땡잡았땡)
2. 카카오 로그인 → 활성화 ON, Redirect URI: `{서버}/auth/callback/kakao`
3. 동의항목: 닉네임(필수). 이메일·전화번호는 **비즈 앱 전환**(사업자등록번호, 무료) 후 설정
4. 앱 키의 **REST API 키** → `KAKAO_REST_KEY` (보안 → Client Secret 쓰면 `KAKAO_CLIENT_SECRET`)
   - 관리자 '카톡 나에게 보내기' 알림과 같은 키를 써도 됩니다. 그 경우 Redirect URI에 관리자 페이지 주소도 함께 등록

## 3. 구글 — console.cloud.google.com
1. 새 프로젝트 → API 및 서비스 → OAuth 동의 화면 (외부, 앱 이름·이메일 입력, 범위: email·profile·openid) → **게시**
2. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션
3. 승인된 리디렉션 URI: `{서버}/auth/callback/google`
4. 받은 값 → `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`

## 4. 확인
- `{서버}/health` 에서 `login: {naver: true, kakao: true, google: true}` 이면 끝
- 사이트 우측 위 [로그인] → 버튼 눌러 가입 → [내 정보] 확인
- 모두 켜지면 build.py 상단 문구를 "네이버·카카오·구글로 3초 가입"으로 바꾸기

## 회원이 되면 달라지는 것
- 주문 내역이 기기와 상관없이 [주문조회]에 자동으로 보임
- 결제할 때 이름·연락처·배송지 자동 입력, 찜 목록 동기화
- 개인정보처리방침에 간편 로그인 항목 반영 완료

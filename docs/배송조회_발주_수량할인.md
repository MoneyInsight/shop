# 배송 단계 조회 · 발주 · 수량 할인

## 배송 단계 (접수→집하→이동중→배송출발→배송완료)
- 관리자 주문 화면에서 택배사·송장번호만 넣고 저장 → 자동 '배송중' + 고객 출고 알림
- 서버 설정값 `TRACKER_CLIENT_ID`, `TRACKER_CLIENT_SECRET` (tracker.delivery 콘솔에서 발급)을 넣으면
  고객 주문조회에 단계 막대·이동 기록이 보이고, 2시간마다 확인해서 배송완료면 상태 자동 변경 + 리뷰 요청
- 키가 없으면 '택배사에서 보기' 버튼(공식 조회 화면 바로가기)만 보임

## 발주 (관리자 › 발주 탭)
1. 도매처별 [주문서 받기] → 도매처 사이트 '엑셀 대량주문'에 업로드 → 예치금 결제
2. [발주 완료] → 주문이 '상품준비중'으로
3. 도매처 송장 엑셀을 복사해 [송장 한 번에 넣기]에 붙여넣기 → 송장 입력·배송중·출고 알림 자동
- 주문서 열 이름/순서는 config.json `order_sheets` 에서 도매처 양식에 맞춤 (양식 받으면 맞춰 드림)
- 배송메시지 끝에 우리 주문번호(T…)가 들어가서 송장 파일에서 주문을 자동으로 찾음

## 수량 할인 (상품 가져올 때 자동 계산)
- n개 원가 = 상품원가 × n + 배송비 × 택배 건수 → 12% 공식으로 n개 가격 → 개당 가격
- 택배 1건에 넣는 개수: 도매처 '수량별 부과' 값 그대로 / 없으면 배송비 3,500원 이하 = 5개까지 1건 / 3,500원 초과(부피 큼) = 1개당 1건
- 조건부 무료배송(○○원 이상 무료) 기준을 넘으면 배송비 0
- 택배가 한 건 늘어나는 수량에서 개당 가격이 다시 오르지 않게 맞춤, 11개 이상은 10개 가격
- 3개 살 때 3% 이상 싸지는 상품만 상품 페이지에 할인표 표시 (계산은 모든 상품에 적용)
- 설정: config.json `pricing.qty_price` (max_ship_won, default_box_qty)

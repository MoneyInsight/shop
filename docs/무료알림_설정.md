# 무료 알림 설정 (웹 푸시 · 이메일)

## 1. 웹 푸시 — 설정할 것 없음
서버가 켜지면 바로 작동합니다. 키도 서버가 알아서 만듭니다.

- **고객**: 주문 완료 화면의 [배송 알림 받기], 가격 제안 후 [답변 오면 알림 받기]를 누르면
  제안 수락·거절, 주문 완료, 출고 알림이 휴대폰에 뜹니다.
- **대표님**: 휴대폰에서 관리자 페이지 › 대시보드 › [이 기기 알림 켜기]
  → 주문·가격 제안·문의·취소/반품 요청이 올 때마다 알림이 뜹니다.
- 안드로이드: 크롬에서 바로 됩니다.
- 아이폰: 사파리 › 공유 › **홈 화면에 추가**로 앱을 설치한 뒤, 그 앱에서 알림을 켜야 합니다.

## 2. 이메일 — Brevo 무료 (하루 300통)
1. brevo.com 무료 가입 (카드 등록 없음)
2. Senders(보내는 사람)에 보낼 주소 등록 후 인증 메일 확인
3. SMTP & API › API Keys › 새 키 만들기
4. Netlify 환경변수에 아래 값을 넣기

| 이름 | 값 |
|---|---|
| BREVO_API_KEY | Brevo API 키 |
| MAIL_FROM | 2번에서 인증한 보내는 주소 |
| ADMIN_EMAIL | 대표님이 알림 받을 메일 (안 넣으면 scream0506@gmail.com) |

- 고객: 주문서·가격 제안에 이메일을 적은 경우에만 메일이 갑니다.
- 대표님: 주문·제안·문의가 올 때마다 메일이 옵니다.
- 키가 없으면 메일은 보내지 않고 나머지는 정상 작동합니다.

# 주문 들어오면 대표님 카카오톡으로 알림 받기 (무료)

카카오톡 **나와의 채팅**으로 알림이 옵니다. 발송 비용은 없습니다.
알림 종류: 새 주문 · 가격 제안 · 상품 문의 · 1:1 문의 · 주문 취소/반품/교환 요청

## 1. 카카오 디벨로퍼스에서 앱 만들기 (한 번만)
developers.kakao.com 에 대표님 카카오 계정으로 로그인 → 내 애플리케이션 → 애플리케이션 추가 (앱 이름: 땡잡았땡)

만든 앱에서 아래 4가지를 설정합니다.

| 설정 | 넣을 값 |
|---|---|
| 플랫폼 › Web › 사이트 도메인 | `https://moneyinsight.github.io` |
| 카카오 로그인 › 활성화 | ON |
| 카카오 로그인 › Redirect URI | `https://moneyinsight.github.io/shop/admin.html` |
| 동의항목 › 카카오톡 메시지 전송 | 선택 동의 |

## 2. 서버에 키 넣기
앱 키의 **REST API 키**를 복사해 Netlify 환경변수에 넣습니다.

| 이름 | 값 |
|---|---|
| KAKAO_REST_KEY | REST API 키 |
| KAKAO_CLIENT_SECRET | (보안 › Client Secret을 켠 경우에만) |

## 3. 관리자 페이지에서 연결
관리자 페이지 → 대시보드 → **카카오톡 연결하기** → 카카오 로그인 → 동의
→ 카카오톡 나와의 채팅에 "알림이 연결되었습니다"가 오면 끝입니다.

※ 서버가 켜진 뒤(Netlify 결제 또는 Cloudflare 연결)에 작동합니다.
※ 고객에게 보내는 알림(제안 수락·주문 완료·출고)은 카카오 알림톡(건당 13원)으로 별도이며, `알림톡_템플릿.md`를 참고하세요.
